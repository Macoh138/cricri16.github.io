# Los inicios de Cricri

Página web estática creada con HTML, CSS y JavaScript.

## Publicarla gratis con GitHub Pages

GitHub Pages puede alojar este sitio gratuitamente. La dirección gratuita tendrá el formato:

`https://TU-USUARIO.github.io`

1. Crea una cuenta en GitHub.
2. Crea un repositorio público llamado `TU-USUARIO.github.io`, reemplazando `TU-USUARIO` por tu nombre de usuario.
3. Sube `index.html`, `style.css`, `script.js` y `cricri.jpg` al repositorio.
4. Entra en **Settings → Pages**.
5. En la fuente de publicación selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios.
7. Después de que GitHub publique el sitio, podrás entrar en `https://TU-USUARIO.github.io`.

Los cambios pueden tardar unos minutos en aparecer.

Importante: `github.io` es un subdominio gratuito. Un dominio personalizado como `cricri.com` normalmente requiere registrar/comprar ese dominio.
